FIRE DETECTION BBox 구분 방식 및 오검출 억제 수정 (2026-08-14)

1. 메인 4. FIRE DETECTOR SETTING
- FIRE DETECTOR 체크박스 아래에 구분 방식 1 / 구분 방식 2 버튼 추가
- 버튼 아래에 HOT PIXEL THRESHOLD / MINIMUM FIRE DETECTOR AREA 배치
- 기본값: 구분 방식 2
- 방식 1: 검출된 전체 화염 후보를 하나의 BBox로 표시
- 방식 2: 가까운 화염 조각만 병합하고 떨어진 화염은 개별 BBox로 표시

2. 독립 FireCandidateValidator
- 메인과 동일한 구분 방식 1 / 2 버튼 및 기본값 2 적용
- 이미지와 동영상 결과에 선택값 즉시 반영

3. 일상 고온 배경 오검출 억제
- 넓고 수평이며 내부가 단단히 채워진 지붕/지면형 윤곽 제외
- 실장비 IR 및 동영상에서 프레임 간 변화량이 부족한 정적 고온 표면 제외
- 카메라 이동처럼 화면 전체 변화량이 큰 구간은 일시 제외
- 불꽃처럼 불규칙한 형상과 시간 변화가 연속 확인된 경우에만 확정 표시

4. 실제 IR 화면 적용 경로
- FIRE DETECTOR 활성화 시 실제 IR RTSP 프레임을 ThermalFireDetectionService에서 처리
- 처리된 동일 BitmapSource가 메인 IR 화면과 IR 분리 화면에 전달됨
- 적색 FIRE DETECTION BBox는 실제 IR 화면에도 표시됨

주의: 방사온도 원본이나 AI 추론이 아닌 영상 기반 보조 검출이므로 실제 화재 확정/경보 판단을 대체하지 않는다.
