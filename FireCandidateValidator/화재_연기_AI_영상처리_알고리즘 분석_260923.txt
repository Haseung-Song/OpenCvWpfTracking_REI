이 문서는 현재 REI Viewer가 EO/IR 영상, AI Detector Agent 결과, 자체 FIRE/SMOKE
영상처리를 어떤 순서로 결합하는지 이해하기 위한 기술 메모이다.
V.SCORE는 학습 모델의 확률이 아니라 자체 영상처리 Track의 시공간의 증거 점수이다.


1. 전체 처리 구조
-------------------------------------------------------------------------------

[카메라 입력]
  EO RTSP --------------------┐
                              ├─ Viewer 프레임 처리
  IR RTSP --------------------┘       ├─ AI BBox Overlay
                                     ├─ FIRE 자체 영상처리
                                     ├─ SMOKE 자체 영상처리
                                     ├─ AI/자체 영상처리 중복 억제
                                     └─ 이벤트·CSV·화면 표시

[AI Detector Agent]
  RTSP 0(EO), RTSP 1(IR)을 별도 분석한 뒤 CMD 55 탐지 데이터를 Viewer로 전달한다.
  Viewer는 Object ID, Class Index, Confidence, BBox 좌표를 파싱한다.
  Viewer 자체 FIRE/SMOKE 영상처리는 AI Agent와 독립적으로 실행된다.

2. AI Detector Agent 연동
-------------------------------------------------------------------------------

2.1 연결 순서
  1) AI CONNECT 버튼을 누르면 입력 IP/Port로 Agent에 연결한다.
  2) RTSP 주소와 ONNX 모델 목록을 조회한다.
  3) RTSP 0/1과 ONNX 모델의 매핑을 설정·조회한다.
  4) 기본 모델은 EO/IR 모두 다음 모델을 우선 선택한다.
     Real-Time-Smoke-Fire-Detection-YOLO11n-main.onnx
  5) 연결 성공 시 FIRE와 SMOKE 체크박스를 함께 켠다.
  6) AI DISCONNECT 시 두 체크박스를 끄고 영상처리 기준 프레임·Track도 초기화한다.

2.2 기본 AI 설정값
  Mapping Confidence = 0.15
  Mapping IOU        = 0.45
  UI 표시 Confidence = 0.15

2.3 클래스 명칭 매칭
  1) Agent에서 모델별 Class 배열과 ONNX Index를 가져온다.
  2) RTSP별 Mapping 정보로 현재 RTSP가 사용하는 ONNX Index를 찾는다.
  3) CMD 55의 Class Index를 해당 모델의 Class 배열에 대입한다.
  4) 매칭되면 SMOKE, FIRE, CAR 등 실제 이름을 표시한다.
  5) 모델 정보가 없거나 범위를 벗어나면 CLASS n 형식을 유지한다.

2.4 AI 이벤트
  Confidence 필터를 통과한 BBox만 화면과 AI 이벤트 목록에 사용한다.
  이벤트 TYPE은 고정 AI가 아니라 매칭된 클래스명으로 기록한다.
  AI 결과가 사라지면 기존 ACTIVE 행을 CLEARED로 전환한다.
  파노라마 PTZ 이동이 시작되면 이동 직전 AI BBox와 Snapshot을 지운다.


3. 자체 FIRE 영상처리
-------------------------------------------------------------------------------

3.1 목적
  IR Palette 또는 명암 영상에서 국부 고온 후보를 찾는다.
  실제 온도값을 수신해 절대 온도를 판단하는 열화상 계측 알고리즘은 아니다.
  화면 명암·색상·움직임·형상 변화로 FIRE 후보를 판정한다.

3.2 처리 순서
  1) 설정된 HOT PIXEL THRESHOLD를 0~255 임계값으로 변환한다.
  2) 현재 Palette에 대응하는 고온 명암 후보 마스크를 만든다.
  3) 5×5 Gaussian Blur로 RTSP 압축 노이즈를 줄인다.
  4) 3×3 Open, 9×9 Close 형태학 연산으로 점 노이즈를 제거하고 화염 조각을 연결한다.
  5) Contour와 BBox를 구한다.
  6) 면적, 채움률, 종횡비, Convex Hull Solidity, 외곽 불규칙도를 계산한다.
  7) 이전 Gray 프레임과의 국부 움직임을 계산한다.
  8) 이전 고온 마스크와의 외곽 변화를 계산한다.
  9) 고정 지붕·전등·태양 반사처럼 형태와 위치가 고정된 고온 영역을 제거한다.
 10) 4프레임 연속 확인 후 FIRE ACTIVE로 확정한다.
 11) 8프레임 미검출 시 CLEARED 처리한다.

3.3 작은 화염과 큰 화염
  Small Fire lane은 24 px 이상의 Contour부터 별도로 검증한다.
  약 36×36 px 이하 후보는 작은 화염용 낮은 움직임 임계값을 사용한다.
  큰 세로형·불규칙 후보는 압축 영상에서도 유지될 수 있도록 별도 조건을 사용한다.
  화면 대부분이 움직이는 경우(global motion ratio > 0.25)는 후보를 억제한다.

3.4 FIRE 구분 방식
  구분 방식 1: 확인된 모든 화염을 하나의 통합 BBox로 표시
  구분 방식 2: 독립된 화염별 BBox로 표시
  현재 기본값: 구분 방식 2

3.5 FIRE V.SCORE
  시작점은 약 70점이며 지속 프레임과 후보 면적을 가산한다.
  최대값은 96점이다.
  FIRE V.SCORE 역시 온도 확률이나 AI Confidence가 아니라 영상 증거 점수이다.


4. 자체 SMOKE 영상처리: 공통 전처리
-------------------------------------------------------------------------------

4.1 기준 프레임
  현재 프레임을 Gray로 변환하고 9×9 Gaussian Blur를 적용한다.
  약 60 분석 프레임 동안 유지되는 장기 기준 프레임과 현재 프레임을 비교한다.
  바로 이전 프레임만 비교하지 않으므로 천천히 증가하는 연기 농도도 잡을 수 있다.

4.2 변화량 임계값
  UI의 Smoke Change Threshold 비율을 0~255 값으로 변환한다.
  범위는 최소 4, 최대 40으로 제한된다.

  기본 BALANCED:
      Minimum Area Ratio = 0.0015
      Change Threshold   = 0.035

  SENSITIVE:
      Minimum Area Ratio = 0.0005
      Change Threshold   = 0.015

  STRICT:
      Minimum Area Ratio = 0.0030
      Change Threshold   = 0.055

4.3 형태학 처리와 시간 마스크
  3×3 Open으로 작은 점 노이즈를 제거한다.
  13×13 Close로 인접 연기 조각을 연결한다.
  최근 후보 마스크를 0.82 감쇠 계수로 누적한다.
  누적 마스크를 42 임계값으로 다시 이진화한다.
  이 과정이 한두 프레임 끊기는 연기 외곽과 BBox 깜빡임을 완화한다.

4.4 전역 변화 차단
  화면 변화 비율이 18%를 넘으면 PTZ 이동·Zoom·노출 급변 가능성이 크다고 본다.
  자동 이동 보정 상태에서는 기준 프레임과 Track을 초기화한다.
  일반 분석에서도 전역 변화가 18% 이하인 경우에만 개별 후보를 생성한다.


5. EO 흰 연기·검은 연기 후보 생성
-------------------------------------------------------------------------------

5.1 흰 연기
  현재 프레임이 기준 프레임보다 밝아진 영역을 사용한다.
  HSV 범위 H=0~179, S=0~105, V=35~245의 저채도 영역만 남긴다.

5.2 검은 연기
  현재 프레임이 기준 프레임보다 어두워진 영역을 사용한다.
  흰 연기보다 변화 임계값을 높게 적용한다.
  HSV 범위 H=0~179, S=0~135, V=15~210을 사용한다.
  완전 암부와 채도가 높은 색상 물체를 줄이기 위한 범위다.

5.3 구조물 경계 억제
  Canny 70/150으로 강한 구조 경계를 구한다.
  3×3 팽창 후 후보 마스크에서 제거한다.
  후보 ROI의 경계 밀도가 0.16을 넘고 후보 채움률이 0.34 미만이면
  건물 외벽·창틀 등 구조물 후보로 판단해 제거한다.


6. IR SMOKE 보조 후보
-------------------------------------------------------------------------------

  IR은 밝아짐·어두워짐을 분리하지 않고 절대 프레임 차이를 사용한다.
  평균+편차 기반으로 국부 고온 핵을 찾고 9×9로 팽창한 뒤 SMOKE 마스크에서 뺀다.
  고온 핵은 FIRE가 우선하고, 주변의 저대비 이동 플룸만 IR SMOKE 후보로 사용한다.
  IR 단독 결과는 실제 연기 확정 의미보다 보조 후보 의미가 강하다.


7. SMOKE Contour와 Track 검증
-------------------------------------------------------------------------------

7.1 Contour 기본 조건
  최소 면적은 max(96 px, Frame Area×설정 최소 면적 비율)이다.
  EO BBox 최대 영역은 화면의 18%, IR은 35%이다.
  Contour 면적 자체의 최대값은 EO 화면의 25%, IR은 45%이다.
  채움률은 EO 0.10 이상, IR 0.035 이상이어야 한다.
  채움률 0.92 초과, 지나치게 가늘거나 넓은 후보, 높이가 너무 작은 후보는 제외한다.
  한 프레임에서 큰 후보 순으로 최대 6개까지만 추적한다.

7.2 후보 병합
  IoU가 있거나 화면 크기 기준 근접 간격에 들어온 연기 조각을 병합한다.
  동일 플룸의 분절이 여러 이벤트로 생기는 것을 줄인다.

7.3 시간축 확정
  EO: 36프레임 지속 확인
  IR: 14프레임 지속 확인

  단순 지속만으로는 부족하며 다음 조건도 필요하다.
  - 필요한 수 이상의 동적 형상 표본
  - 상향 이동 또는 면적 확장 표본
  - 하향 이동이 상향 이동보다 지속적으로 많지 않을 것
  - 장시간 완전 고정 후보가 아닐 것

7.4 BBox 연속성
  이전 BBox 42%, 현재 BBox 58% 가중 평균으로 위치·크기를 평활화한다.
  최근 Track 외곽을 Envelope로 누적해 연기의 일부 조각만 잡히는 문제를 줄인다.
  Envelope는 120프레임 또는 화면 22% 초과 시 현재 BBox부터 다시 시작한다.

7.5 SMOKE 구분 방식
  구분 방식 1: 화면의 확정 SMOKE를 하나의 통합 BBox로 표시
  구분 방식 2: 독립된 연기 기둥별 BBox로 표시
  현재 기본값: 구분 방식 2


8. 2026-09-02 차량 강체 이동 오탐 억제
-------------------------------------------------------------------------------

8.1 확인된 원인
  로그 08:42:29:
      최초 이벤트 BBox 289×221, V.SCORE 35.4%
      1.5초 뒤 이동 경로 Envelope 747×241, V.SCORE 78.2%

  로그 08:42:43:
      최초 이벤트 BBox 228×200, V.SCORE 34.7%
      1.5초 뒤 BBox 338×226, V.SCORE 70.1%

  차량이 화면 위쪽으로 이동하면 기존 UpwardSamples가 증가했다.
  이동 중인 차량의 과거 위치가 Envelope에 누적되면서 면적·확산 점수도 증가했다.
  즉, 실제 배기가스가 아니라 차량 본체와 이동 궤적이 플룸 증거로 사용된 것이 문제였다.

8.2 새 Track 측정값
  SignificantMotionSamples : 1.5 px 이상 이동한 표본 수
  CoherentMotionSamples    : 이전 이동 벡터와 cosine 0.70 이상인 표본 수
  DirectionChangeSamples   : cosine 0.25 이하로 방향이 바뀐 표본 수
  RigidTranslationSamples  : 면적 변화 10% 미만+종횡비 변화 10% 미만인 이동 표본 수
  DeformationSamples       : 면적 변화 8% 이상 또는 종횡비 변화 10% 이상인 표본 수
  Net Displacement         : 최초 중심점부터 현재 중심점까지의 순이동 거리

8.3 강체 이동 판정 조건
  EO 후보에만 적용한다.
  이동 표본이 max(8, 확인 프레임/4) 이상이어야 한다.
  순이동 거리가 화면 대각선의 0.6% 이상이어야 한다.
  순이동 거리가 최초 BBox 대각선의 32% 이상이어야 한다.
  누적 이동 거리가 최초 BBox 대각선의 70% 이상이어야 한다.
  강체 이동 표본 비율이 55% 이상이어야 한다.
  이동 방향 일관성이 55% 이상이어야 한다.
  변형 표본 비율은 35% 이하여야 한다.
  방향 급변은 전체 이동 표본의 1/4 이하이어야 한다.

8.4 실제 연기를 유지하는 이유
  실제 공장/화재 연기는 바람에 이동할 수 있지만 면적·종횡비·외곽이 계속 변한다.
  따라서 DeformationSamples가 증가하여 강체 조건에서 벗어난다.
  위치만 바뀌고 형태가 유지되는 차량·사람 등 강체 후보만 억제 대상이다.
  강체 이동 우세 단계부터 Envelope를 현재 BBox로 재설정해 차량 궤적 확대도 막는다.

8.5 로그
  억제 발생 시 다음 로그가 최대 2초에 한 번 기록된다.
      [SMOKE ROAD MOTION]
      Rigid moving-object candidate suppressed / CHANNEL=EO / COUNT=n

8.6 추가 차량 융합 및 발생점 이동 판정(_14)
  AI가 CAR, TRUCK, BUS, VAN, VEHICLE, MOTORCYCLE 등을 제공하면 해당 BBox를
  2초 동안 동적 도로 활동 구간으로 사용한다. 차량 주변 그림자·반사·배경 가림을
  포함하도록 수평 80%, 위 45%, 아래 35% 범위로 확장하며, 자체 SMOKE 후보의
  중심·하단 발생점 또는 면적 12% 이상이 겹치면 제거한다.

  AI 차량 클래스가 없는 Smoke/Fire 전용 모델에서도 자체 Track의 BBox 하단
  중심점을 발생점으로 보고 별도 추적한다. 발생점 이동 표본 8개 이상, 화면
  대각선 대비 순이동 0.4% 이상, 최초 BBox 대각선 대비 순이동 25% 이상,
  누적 이동 65% 이상, 방향 일관성 55% 이상이면 이동 발생점으로 억제한다.
  굴뚝·화점은 하단이 고정되고 상부만 변형되므로 이 조건과 분리된다.


8.7 다중 플룸·화점 독립 Track 연속성(_15)

  - 영상 확인 결과 좌·우 독립 연기가 존재해도 한 Track의 마스크가 약해진 순간
    다른 Track만 표시되면서 BBox가 교대하는 현상이 확인되었다.
  - SMOKE는 최대 12개 후보를 입력받고, 각 플룸이 최초 확정되면 독립 상태를 래치한다.
  - 확정 플룸은 최대 108프레임의 일시 누락을 허용하며 재검출 시 기존 Track과
    다시 연결된다. 차량 강체·이동 발생점 판정을 받은 Track은 유지하지 않는다.
  - 확정 Track은 중심점 게이트를 0.55배로 축소해 인접 플룸으로 ID가 이동하는
    현상을 줄이고, 실제 중첩도가 높은 중복 Track만 하나로 합친다.
  - FIRE는 각 화점을 4프레임 확인한 뒤 개별 Track으로 표시하고 45프레임 동안
    순간 누락을 허용한다. 전체 FIRE 해제도 동일한 45프레임 기준을 사용한다.
  - 상태 확인 로그:
      SMOKE TRACK CONTINUITY / VISIBLE=n / HELD=n
      THERMAL FIRE TRACK / VISIBLE=n / HELD=n
  - 하이브리드 중복 억제는 유지 Track에도 동일하게 적용된다. AI SMOKE와 겹치는
    자체 SMOKE Track은 표시하지 않으며, AI FIRE/FLAME Snapshot과 겹치는 현재·유지
    FIRE Track도 제거한다. AI가 놓친 위치의 자체 후보만 독립적으로 보완 표시한다.
  - FIRE 중복 억제 상태는 THERMAL FIRE HYBRID 로그로 확인한다.


8.8 도로 다중 객체 집합 억제와 AI 표시 연속성(_16)

  - 여러 차량의 후보가 같은 Track에 편입되면 하단 발생점이 화면의 넓은 범위를
    이동하고 방향 전환·급격한 점프가 반복된다. 이 특성과 8% 이상 대형 외곽을
    조합해 도로 집합 Track을 실제 고정 발생점 플룸과 분리한다.
  - 누적 외곽이 현재 후보 면적의 2.4배 이상이고 발생점 이동 범위가 넓으면 외곽을
    즉시 현재 후보부터 다시 시작하여 도로 전체로 커지는 BBox를 차단한다.
  - AI UI는 Dispatcher 병합 시 검출 Pending Frame을 빈 Frame보다 우선하며,
    검출 직후의 짧은 빈 구간은 750ms 표시 유지로 보완한다.
  - 기본 AI 설정: Confidence 0.15 / IOU 0.50 / Box Filter 0.12.
  - 확인 로그: SMOKE ROAD MOTION의 TRAFFIC, AI BBOX HOLD.


9. SMOKE V.SCORE
-------------------------------------------------------------------------------

  V.SCORE는 AI Confidence가 아니다.
  최초 약 1.5초 동안 Track의 시공간 특성을 평가한 뒤 고정한다.

  주요 구성:
  EO 기본점수 22, IR 기본점수 20
  BBox 면적 비율 최대 +12
  세로성 최대 +4
  종횡비 균형 최대 +3
  1.5초 지속성 최대 +20
  상향 이동 최대 +8
  면적 확장 최대 +10
  중심 이동 최대 +5
  형상 변화 최대 +5
  고정 얼룩 조건 충족 시 -15
  최종 범위 5~92

  2026-09-02 이후 강체 이동 차량은 V.SCORE 계산·이벤트 단계 전에 제거된다.
  따라서 차량 이동 자체가 높은 V.SCORE로 승격되는 경로를 차단한다.


10. AI와 자체 영상처리의 하이브리드 동작
-------------------------------------------------------------------------------

  AI가 Confidence 기준을 통과한 SMOKE BBox를 수신하면 2초 Snapshot으로 보관한다.
  자체 SMOKE BBox와 AI BBox의 겹침을 계산한다.
  작은 BBox 기준 중첩 35% 이상 또는 Union 기준 IoU 12% 이상이면 중복으로 본다.
  AI가 이미 잡은 SMOKE는 AI 목록에만 남기고 자체 영상처리 중복 BBox·이벤트는 억제한다.
  AI가 못 잡은 독립 위치의 자체 SMOKE는 그대로 표시한다.
  FIRE와 SMOKE가 같은 영역에 겹치면 FIRE를 우선하고 자체 SMOKE 후보를 제거한다.

- 화면 경계 또는 내부에서 장시간 위치·크기가 거의 고정된 후보만 정적 고온물체로 억제한다.
- 연속 형상 변화가 다시 나타나면 억제를 해제하여 지속되는 실제 화염을 재평가한다.
- 최종 FIRE 상태는 정적 고온물체 억제를 통과한 Persistent Track으로만 갱신한다.

3. FIRE 설정 UI 및 기본값
- FIRE SOURCE는 현재 로컬 분석 구조에 맞춰 IR ONLY로 고정한다.
- FIRE SENSITIVITY는 SENSITIVE/BALANCED/STRICT 프리셋을 제공한다.
- 기본 BALANCED는 Hot Threshold 0.76, Minimum Area Ratio 0.0015를 사용한다.
- SENSITIVE는 0.68/0.0010, STRICT는 0.82/0.0030이며 기존 Slider 값과 동기화한다.
- 프리셋 변경 시 이전 조건에서 누적된 IR FIRE Track을 초기화한다.

4. EO SMOKE 진단 및 지속성 보완
- SmokeDiagnostics의 최신 오탐은 폭 약 34px, 높이 약 383px인 창틀/벽면 세로 경계였다.
- 성숙 플룸이 아닌 극단적으로 가늘고 긴 세로 구조만 Track 후단에서 제외한다.
- 일반 후보의 일시 누락 유지시간은 확인 프레임 수준으로 줄여 사라진 오탐 BBox의 잔류를 줄였다.
- 장시간 상승·확산·변형이 검증된 IsVerifiedPlume의 긴 유지시간은 그대로 보존한다.

5. 성능·로그·검증
- 추가 판정은 Track별 상수 시간 연산만 사용하며 영상 픽셀 전체 재순회를 추가하지 않는다.
- 상태 로그는 VISIBLE/HELD/STATIC_HOTSPOT_SUPPRESSED 수가 바뀔 때만 제한 기록한다.
- Release x64 빌드를 통과했으며 현장에서는 IR ONLY/BALANCED로 고정 열원과 실제 화염을
  각각 확인한 뒤 필요 시 프리셋만 조정한다.
- FIRE/SMOKE 테스트 프로그램도 별도 FireCandidateAnalyzer에 동일한 고정 열원 Track 보조 필터를
  적용하여 Viewer와 오프라인 검증 결과의 판정 방향을 일치시켰다.
