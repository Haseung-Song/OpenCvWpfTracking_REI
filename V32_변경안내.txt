기존 DISPLAY OVERLAY 보더와 큰 토글 버튼을 제거했습니다.
오른쪽 장비 제어에서 십자선 표시·설정 항목을 제거했습니다.
EO/IR 각 영상의 배율 버튼 바로 위에 작은 '십자선 ⚙' 버튼을 배치했습니다.
버튼을 누르면 해당 채널의 설정 패널이 영상 안쪽 위로 열립니다.
표시 체크박스는 기존 고정 적색 십자선을 EO/IR에 공통 표시·숨김 처리합니다.
채널 선택칸 없이 연 영상의 EO/IR을 자동 선택하고
표시 체크박스와 '수동 계산(4점)'·'기본 중심' 두 버튼만 제공합니다.
개별 수동·자동·저장·취소 버튼을 제거하고 4점 교점이 유효하면 자동 적용·저장합니다.
제목과 표시 체크박스를 한 줄로 통합하고, 초기 안내 문단은 제거했습니다.
닫기·연결 해제·분리창 채널 변경 시 후보 선택은 취소하고 기존 저장값은 유지합니다.
실제 원본 영상의 표시 영역을 기준으로 버튼·패널을 배치하며
메인·서브 교환, 창 크기 변경 및 분리창에서도 여백으로 벗어나지 않도록 제한합니다.
작은 영상에서는 설정 내부에만 스크롤을 적용하고 영상과 오른쪽 UI 크기를 늘리지 않습니다.
설정 패널 클릭은 PT 클릭 이동·영상 드래그로 처리하지 않습니다.
4점 보정 시작 시 패널을 잠시 접어 영상 중심의 점 선택을 방해하지 않습니다.
선택 중에는 버튼 옆에 단계 안내를 표시하고 계산 완료 후 작은 결과 패널을 다시 엽니다.
EO 16:9 / IR 5:4 실제 영상 영역의 폭·높이에 따라 보더 폭과 최대 높이를 조절합니다.
보더 폭은 최대 238 DIP이며 작은 IR 영상에서는 더 작게 표시합니다.
패널 높이는 실제 영상 높이의 36% 이내로 제한하고 필요한 경우 내부 스크롤만 사용합니다.

클릭한 기준물 위치에 A1·B1(낮은 줌), A2·B2(높은 줌) 점과 번호를 표시합니다.
낮은/높은 줌의 기준선은 점선으로, 같은 기준물의 이동선은 얇은 실선으로 표시합니다.
네 번째 점 이후 두 이동선을 교점까지 연결하고 계산 중심에 작은 원을 표시합니다.
유효한 교점을 저장하면 적색 십자선이 새 중심으로 이동합니다.
점·선은 원본 정규화 좌표와 실제 영상 영역을 사용해 메인·서브·분리창 크기를 따라갑니다.
그리기는 선택점/표시 영역이 바뀐 경우에만 갱신하며 마우스 입력과 BBox 좌표계는 변경하지 않습니다.
설정 닫기·기본 중심·연결/채널 변경 시 임시 점과 선은 제거하고 저장값은 따로 유지합니다.

보정은 원본 영상 정규화 좌표를 사용합니다.
최신 장비 위치·렌즈 피드백과 같은 장비·채널·줌·고정 PAN/TILT 조건을 검사합니다.
4점 계산은 사용자가 낮은 줌 A/B와 높은 줌 A/B를 선택하는 방식입니다.
D-ZOOM OFF 확인 체크박스는 기본 선택입니다. 이는 실제 OFF 명령이나 장비 응답 확인이 아닙니다.
