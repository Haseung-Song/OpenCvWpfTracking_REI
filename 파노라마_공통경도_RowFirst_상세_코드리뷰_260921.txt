================================================================================
REI / MOE 공통 경도 Row-first 파노라마 상세 코드 리뷰

작성/최종 갱신일: 2026-09-21
================================================================================

[1. 변경 결론]

R15의 Column-first는 전체 360도 연결에는 유리했으나 같은 Pan의 서로 다른 Tilt 원본을
Y축 평행이동만 한 채 먼저 합쳤다. 이 과정에서 가까운 난간과 먼 건물/산의 시차가
픽셀로 고정되어 건물 절단, 난간 꺾임, 유령상이 발생했다.

R16은 다음 구조로 변경했다.

  1~5개 Tilt 행 × Pan 10도 간격 36장 촬영
    → 모든 행에서 실제 10도당 영상 이동 폭 측정
    → 측정값 중앙값 하나를 공통 경도 폭으로 선택
    → 36장 전부 사용하여 각 행의 360도 파노라마 완성
    → 모든 행에 동일한 시작 경도/픽셀 폭 유지
    → 원본 동일 Pan 쌍에서 구한 안정 overlap/Y offset 적용
    → 행 사이 구조 보호 Seam + Laplacian Multi-band
    → 360도 범위 검증 후 JPEG 97 저장

Column-first는 삭제하지 않고 새 경로 예외 시에만 복구 경로로 유지한다.


[2. 촬영 방식]

- Pan 간격: 10도
- 행당 프레임: 36장
- 행 수: 1~5행
- 총 프레임: 36/72/108/144/180장
- PT 속도: 15
- 목표 허용 오차: 0.15도
- 상태 Packet 3회 연속 안정 확인
- 도착 후 1,800ms 추가 대기
- Overlay 적용 전 EO 원본 프레임 사용
- 행별 Forward/Reverse 교대 촬영 후 메모리 순서는 Pan 0~35 정방향으로 통일

Tilt 목표(시작 Tilt가 0도인 경우)

- 1행: 0
- 2행: +12, -12
- 3행: +18, 0, -18
- 4행: +24, +8, -8, -24
- 5행: +30, +15, 0, -15, -30


[3. 공통 경도 폭 결정]

각 행에서 인접 Pan 프레임 35쌍의 실제 수평 이동량을 축소 영상으로 측정한다.
행마다 장면 구성이 다르므로 하늘이 많은 행이나 바닥이 많은 행의 값 하나를 그대로
사용하지 않는다. 각 행의 대표 이동 폭을 구한 뒤 모든 행 대표값의 중앙값을 선택한다.

선택된 commonContributionWidth를 모든 행과 36개 Pan에 동일 적용한다.

따라서 과거 독립 Row-first처럼 다음 현상이 발생하지 않는다.

- 행마다 360도 출력 폭이 달라지는 현상
- 최소 폭에 맞추면서 특정 행만 확대/축소되는 현상
- 각 행의 시작/끝 경도가 달라지는 현상
- 행 전체가 좌우로 어긋나 수평 층으로 분리되는 현상


[4. 행별 360도 합성]

각 원본 프레임 중앙에서 공통 10도 폭에 해당하는 영역을 사용한다. 인접 프레임의
실제 중첩부에서는 영상 차이와 Edge 비용을 이용한 세로 Seam을 찾고 Laplacian
Multi-band로 합성한다. 과거 최종 Stitcher 입력의 24장 선택은 새 정상 경로에서
사용하지 않는다. 36장을 모두 사용하므로 가까운 난간/기둥에서 20도 간격이 생기지 않는다.

중앙행에서 계산한 Pan 방향 노출 gain을 모든 Tilt 행에 공통 적용한다. 행마다 서로
다른 Pan gain을 계산해서 세로 방향 색상 블록이 생기는 것을 방지한다.

인접 Tilt 행의 평균 밝기는 여러 동일 Pan 원본에서 측정하고 중앙행을 1.0으로 둔
center-anchored row gain으로 보정한다.


[5. 행 사이 세로 결합]

완성된 대형 행 영상에서 overlap을 다시 추정하지 않는다. 하늘/산 경계가 강하면
대형 영상 추정기가 잘못된 산 능선을 선택할 수 있기 때문이다.

대신 각 인접 Tilt 행의 동일 Pan 원본 약 9방향에서 overlap과 Y offset을 측정하고
중앙값을 사용한다. 이 값은 행별 360도 완성 전부터 세로 최종 결합까지 유지된다.

- Pan 방향별 제각각 Y warp: 사용 안 함
- 행별 독립 확대/축소: 사용 안 함
- 행별 수평 Crop/Shift: 사용 안 함
- 공통 경도 폭: 사용
- 원본 기반 공통 overlap: 사용
- 원본 기반 공통 Y offset: 최대 +/-8px
- 구조 보호 동적 Seam: 사용
- Laplacian Multi-band: 사용


[6. 실패 및 안전 복구]

정상 우선 경로:

  ComposeSharedLongitudeRowFirstPanorama()

다음 조건이면 정상 경로를 실패 처리한다.

- 행 개수/프레임 개수 불일치
- 공통 경도 행 결과 폭 불일치
- 빈 Mat
- 360도 최소 폭 검증 실패
- OpenCV/메모리 예외

실패 시 기존 ComposeV21TwoRowColumnFirst() 또는 ComposeColumnFirstFullCircle()을
한 번만 시도한다. 두 경로가 모두 실패하면 잘못된 영상을 저장하지 않는다.


[7. 실제 5행 원본 오프라인 재현]

입력 위치:
  D:\Project\2. C#\Main_Project\REI_TEST\bin\x64\Debug\Panoramas\
  panorama_debug\capture

입력은 실제 5행 x 36장, 총 180장이다.

공통 폭 후보:
  220, 244, 264, 276, 280px

선택 중앙값:
  264px / 10도

회귀 시험 결과:

- 2행: 9504x1555, 약 3.4초
- 3행: 9504x2030, 약 5.9초
- 4행: 9936x2523, 약 7.4초
- 5행: 9504x3004, 약 9.9초

4행은 해당 행 조합의 중앙 공통 폭이 276px이므로 276x36=9936px이다.
각 시험은 전체 범위 검증과 저장을 통과했으며 예전 4행 OpenCV 결과 3077px보다
원본 세부 정보가 훨씬 많이 유지된다.

최초 R16 시험에서는 완성된 행에서 overlap을 재추정하여 4행 산 능선이 중복되는
사례가 발견됐다. 이를 통과 결과로 두지 않고 원본 동일 Pan 쌍의 안정 Geometry를
재사용하도록 수정했다. 재시험에서 해당 큰 산 중복은 제거됐다.


[8. 현재 남는 한계]

R16은 카메라 Calibration 파일이 없는 상태에서 적용 가능한 안전한 공통 각도 방식이다.
실제 fx/fy/cx/cy 및 렌즈 왜곡계수가 없으므로 완전한 calibrated spherical projection이나
Bundle Adjustment/APAP를 구현했다고 표현하면 안 된다.

다음 현상은 원본에도 존재하거나 물리적 시차 때문에 일부 남을 수 있다.

- 강한 태양 플레어와 카메라 내부 반사
- 촬영 도중 자동 노출 변화
- PTZ 회전축과 렌즈 광학 중심 차이로 인한 근거리 난간 시차
- Forward/Reverse 접근 방향에 따른 감속기 백래시
- 움직이는 구름/사람/차량

특히 하늘의 넓은 수평 명암 차이는 기하 정합 실패와 구분해야 한다. 원본 Tilt 행의
자동 노출과 렌즈 플레어가 다르면 uniform gain과 Multi-band만으로 완전히 제거할 수 없다.


[9. 다음 단계 후보]

카메라 제조사 또는 체커보드 Calibration으로 다음 값을 확보하면 R17 후보를 진행한다.

- fx, fy, cx, cy
- k1, k2, p1, p2, 필요 시 k3
- 실제 EO 수평/수직 화각
- Zoom 0~100 구간별 파라미터

그 뒤 적용 순서:

1) 렌즈 왜곡 보정
2) 실제 Pan/Tilt 자세 기반 공통 구면 투영
3) PTZ 자세를 prior로 한 제한적 Bundle Adjustment
4) 재투영 잔차가 큰 영역만 APAP/지역 Mesh Warp
5) LSD 직선 검출을 이용한 난간/건물 Line-aware Seam

Calibration 없이 추정값만으로 구면 투영하면 기존보다 건물과 난간이 더 휘어질 수
있으므로 R16에는 임의 파라미터를 넣지 않았다.


[10. 코드 정리]

삭제:

- ComposeTimeBoundedRowFirstPanorama()
- ComposeLegacyRowFirstPanorama()
- BlendRowsVertically()
- EstimateCyclicHorizontalShift()
- ShiftCyclicHorizontally()
- AlignRowsWithoutWrapSeam()
- ApplyUpperRowExposureGain()

앞의 두 함수와 연쇄 보조 함수들은 정상/복구 경로 어디에서도 참조되지 않으면서 서로
다른 폭의 독립 Stitcher 결과를 다시 합치는 과거 구현이어서 제거했다.

유지:

- Column-first 계열: 새 경로 실패 시 안전 복구에 실제 사용
- StitchMatsWithFallback 계열: Column-first 복구에서 실제 사용
- Fixed-angle 계열: 새 공통 경도 정상 경로에서 실제 사용
- Geometry/Seam/Multi-band/검증/Debug 저장: 정상 및 복구 경로에서 실제 사용

화재/연기 알고리즘은 이번 변경에서 수정하지 않았다. 파노라마 서비스에 한정해
참조 여부가 명확한 과거 Row-first 두 함수만 제거하여 다른 기능 회귀 위험을 막았다.
