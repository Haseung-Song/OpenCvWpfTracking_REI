- 2026-10-15 최종 안정화: UI 상태 전환/십자선 조작 로그, 동일 레이아웃·속성 갱신 생략, 공유 팔레트 Brush 캐싱·Freeze, 비정상 화각/분리된 시각 트리 방어 및 예외 로그 1회 제한, AI 수동 해제 소켓 정리 보강. 영상/명령/타이밍 정책 변경 없음.

- IR 영상은 V31_12의 기존 5:4 표시 방식 그대로 유지. 영상/BBOX/십자선에 여백·패딩·별도 footer를 추가하지 않음.
- VideoOverlayPlacement 배치 보정 기능 자체 제거. 영상의 부모 컨테이너·행 구조·Margin·기존 Z-order 변경 없음.
- EO/IR 연결 중 배율/연결 문구 및 경고를 실제 Uniform 영상 사각형 내부에 배치. 상하뿐 아니라 좌우 검은 여백을 제외. 메인/서브/분리창·전환·크기 변경 공통. 영상은 늘리거나 자르지 않음. 해제 시 Disconnected 기존 위치 유지.
- 2026-10-15 부분 롤백: 비활성 이력 국방색 #3F5550 복원. CSV에서 불러온 행은 파랑 #176B87로 구분하고 새 실시간 행은 ACTIVE/CLEARED 상태색 유지.
- 알림 텍스트 FIRE 밝은 빨강 #FF8178 / AI 한 단계 낮춘 형광 초록 #55EE32. 기존 BBOX 색상 상수와 구분.
- 알림 하위 탭 클릭이 상위 탭 '최신 이벤트 선택'으로 되돌아가던 터널링 경로 차단.
- 이벤트 보관 한도는 기존 22×100=2,200에서 AI / FIRE-SMOKE 목록별 9,999건으로 확대. 전체 목록을 한 화면에 그리지 않고 기존 페이지 방식 유지.

- 클릭 이동 화살표는 해당 채널 Connected와 클릭 이동 옵션이 동시에 ON일 때만 표시.
