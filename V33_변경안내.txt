전체 수치는 진단 파일에 보존합니다. 진단 파일은 파일당 10MiB, 최근 10개까지 보관합니다.
경고·오류는 진단 전용으로 숨기지 않습니다. 기존 로그 파일은 삭제하거나 다시 쓰지 않습니다.

읽는 순서: 발생 시각 → 기능·운용 요약 → 미완료 이유 → 목표·실제 수치 → 필요 시 진단 파일.
RAW는 장비 원시값, STANDARD는 화면 표준값이며 LA IR 줌에서는 방향이 반대입니다.
TARGET은 목표, ACTUAL·CURRENT는 실제 수신값, SENT·WRITE SUCCESS는 송신 결과입니다.
Valid는 최신 유효 수신, NotReceived는 미수신, False·INCOMPLETE는 해당 단계 미완료입니다.
RTSP_BITRATE_MBPS는 영상 전송량, DECODE_FPS는 초당 디코딩 수, LAST_FRAME_MS는 최근 프레임 지연입니다.

자체 검증: 기존·IR·안정화·Agent 분리 139개, ZERO·구역 회귀 329개, 실제 콘솔·Serilog 파일 16개 통과.
Debug·Release x64 빌드 통과. 실장비 시험은 별도로 필요합니다.

[추가 보완  IR 줌 장비 상태와 SYNC 보정 분리]

WEB IR 줌의 CURRENT STATUS·영상 배율·새 프리셋 저장은 수신한 0~1000 위치를 그대로 사용합니다.
수신 408은 화면에도 408로 표시하며 기존 끝점 61~934 환산으로 397로 바꾸지 않습니다.
일반 줌 위치 입력·프리셋 복원·일반 도착 판정에도 장비 좌표를 사용합니다.
LA IR의 기존 방향 반전은 유지합니다. 포커스 수신·표시 방식은 변경하지 않습니다.

61~934 끝점 보정과 끝점 학습은 SYNC 단계 적용에서만 사용합니다.
공유 줌 구동부는 기본 장비 좌표이며 SYNC 진입점만 보정 모드를 명시합니다.
SYNC에서 끝점을 학습해도 일반 상태 표시·새 프리셋·일반 명령 좌표는 바뀌지 않습니다.
로그에 DEVICE_POSITION / SYNC_CALIBRATED를 구분해 남깁니다.

기존 WEB 프리셋은 저장 좌표 형식을 구분해 원문과 같은 목표를 호환 복원합니다.
좌표 구분이 없는 과거 CSV는 LEGACY_SYNC, 새 프리셋은 DEVICE_POSITION으로 저장합니다.
유효한 과거 수신 스냅샷이 있으면 그 장비 위치를 우선 사용하며 없으면 과거 기본 범위로 고정 환산합니다.
과거에 별도 끝점 학습을 한 저장본은 재등록으로 실제 위치를 확인하십시오.
기존 사진·JSON·구역·프리셋 번호·팬·틸트·포커스 저장값은 삭제하지 않습니다.


[추가 보완  AF 상태와 프리셋 이동 분리 및 LA / WEB P100 지원]

AF ON·조회 대기·응답 미확인 상태만으로 프리셋 전체 이동을 막지 않습니다.
팬·틸트·줌은 기존 목표로 이동하고, AF ON 또는 미확인 채널의 저장 포커스만 제외합니다.
OFF가 확인된 채널은 저장 포커스까지 복원하며 반대 채널의 AF 상태와 분리해 처리합니다.
프리셋 저장 데이터의 포커스 값은 삭제하거나 변경하지 않습니다.

WEB 장비 GOTO PRESET은 내부 포커스를 복원할 수 있어 보호 채널이 있으면 기존 직접 PTZ 경로를 사용합니다.
일반 프리셋·파노라마 번호 클릭·AUTO SCAN에 같은 기준을 적용합니다.
제외한 채널은 EO/IR FOCUS SKIPPED로 표시하며 자동 초점 완료나 저장 초점 복원으로 표시하지 않습니다.
일반 수동 포커스 명령의 AF 충돌 방지, STOP·연결·좌표 기준·위치 수신 검증은 유지합니다.
연결 시 연속 AF 기본 OFF 설정은 유지하지만 응답 대기 때문에 PTZ 이동을 차단하지 않습니다.

LA / WEB 슬롯은 P01~P100, 총 100개로 통일합니다. 등록·삭제·이동·슬롯 선택·파노라마 번호도 같은 범위를 사용합니다.
P64~P100가 P63으로 바뀌던 송신 번호 제한도 수정하며, PAN/TILT 속도 범위는 바꾸지 않습니다.
LA는 표시 번호 1~100을 내부 ID 0~99로 변환합니다. 기존 LA/WEB 프리셋 목록과 저장값은 유지합니다. P64~P100의 장비 펌웨어 지원은 실장비 확인이 필요합니다.

JPG·좌표 JSON·JSON 백업은 같은 장비 폴더에 함께 보관하며 장비마다 사진 번호를 따로 증가시킵니다.
불러오기 창도 현재 장비 폴더에서 시작합니다.

장비를 판별할 정보가 없는 과거 사진은 직접 불러올 수 있지만 임의의 장비로 자동 분류하지 않습니다.

[추가 보완  지도·파노라마 표시 기준 통일]

LA / WEB 모두 Control Agent TCP 연결 완료 시 지도와 저장 파노라마를 표시합니다.

TCP 연결 해제·재연결 대기 중에는 지도는 기본 로고, 파노라마는 기존 기본 화면으로 돌아갑니다.
확대 지도·파노라마 창과 번호 레이어도 정리하며 사진·JSON·Config·프리셋 연동은 삭제하지 않습니다.

[추가 보완  WEB 연속 자동 초점 기본 OFF]

WEB 연결 후 HOME 등 선행 작업이 끝나면 EO/IR AF 상태를 자동 조회합니다.
연속 AF가 ON인 지원 채널에는 OFF 설정을 한 번 보내고 장비의 OFF 응답을 확인합니다.
이미 OFF이면 불필요한 설정을 보내지 않으며, 단발 AF 전용·미지원·EO 직접 제어 경로는 제외합니다.

OFF 응답이 확인된 채널은 저장 포커스까지 복원합니다. AF 상태와 관계없이 팬·틸트·줌 이동은 허용합니다.
포커스 저장·복원 기능은 제거하지 않습니다. 기존 AUTO FOCUS 단발 버튼도 유지합니다.
AF 기능 사용 체크박스 기본 ON은 제어 사용 여부이며 연속 AF 모드 기본 OFF와 다릅니다.
연결 후 사용자가 명시적으로 AF ON을 선택하면 그 선택은 다시 강제로 끄지 않습니다.

OFF 미응답·오류·검색 진행 상태는 확인 완료로 처리하지 않습니다.
이때는 해당 채널의 저장 포커스만 제외하고 팬·틸트·줌 이동은 유지합니다.
재연결마다 새 장비의 실제 상태를 다시 조회하며 이전 장비의 응답으로 확인하지 않습니다.

좌표 정보가 없는 사진은 기존과 같이 좌표 확인 없이 연동하지 않습니다.
