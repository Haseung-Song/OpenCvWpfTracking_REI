TORUSS EO/IR 통합 관제시스템
V33 변경 안내

현재 버전  V33_1
갱신 일자  2026-10-26


[이번 보완  파노라마 연동 보존]

1. HOME은 같은 좌표계에서의 위치 이동입니다.
   연결 직후 자동 HOME과 수동 HOME으로 파노라마 연동을 무효화하던 처리를 제거했습니다.

2. 연동 번호·사진 좌표·마지막 이미지 경로를 Config/PanoramaLinks에 즉시 저장합니다.
   Config를 우선 저장소로 사용하고 JPG 옆 JSON도 함께 유지합니다.
   임시 저장 후 원자적으로 교체하며 마지막 정상 백업으로 복원합니다.

3. 정상 종료·비정상 종료·장비 해제·같은 장비 재연결 뒤에도 연동을 복원합니다.
   프로그램 교체·PC 이동 시 기존 Config와 파노라마 JPG·JSON을 함께 보존하십시오.
   배포 ZIP에는 운용 중 생성된 사용자 연동·프리셋 기록을 넣지 않습니다.

4. PAN/TILT ZERO가 적용되어도 사진과 연동 번호를 삭제하지 않습니다.
   변경 전 위치와 ZERO 후 새 수신값을 확인해 누적 좌표 변환을 저장합니다.
   기존 프리셋 각도와 위치 스냅샷을 같은 기준으로 갱신하며 렌즈·GPS·IMU 근거는 유지합니다.
   사진 위 실제 지점은 유지하고 표시되는 PAN/TILT 값만 현재 좌표 기준으로 바꿉니다.

5. 좌표 변환과 프리셋 저장 사이에 종료되어도 변경 기록으로 중복 없이 복원합니다.
   ZERO 후 WEB 프리셋은 기존 직접 PTZF 복원 경로를 공유해 장비 슬롯 기준을 추측하지 않습니다.
   새 값이 미확인인 경우 연동은 보존하고 PRESET REFERENCE CHECK REQUIRED로 안내합니다.
   확인되지 않은 기준으로 프리셋 이동·AUTO SCAN을 시작하지 않습니다.

6. 이전 빌드에서 HOME 때문에 무효화된 JSON도 삭제하지 않습니다.
   같은 장비이며 촬영 이후 ZERO가 바뀌지 않았음을 기존 PRESET 연동 버튼에서 확인한 뒤 다시 연결할 수 있습니다.
   실제 ZERO 이력이 불명확하면 임의의 변환값으로 이동하지 않습니다.


[이번 보완  UI와 자동 초점]

1. 파노라마 PRESET 상태 문구와 이동 잠금 문구를 영문으로 통일했습니다.
   P03 PTZF MOVING / P03 PTZF MOVE COMPLETED / PRESET MOVE STOPPED
   PRESET MOVE UNCONFIRMED / PRESET REFERENCE CHECK REQUIRED

2. 새 AF ON/OFF·상태조회 영역만 WEB AGENT 지원 장비에서 표시합니다.
   LA AGENT에는 새 AF 영역과 새 프로토콜 요청을 제공하지 않습니다.
   기존 LENS의 EO/IR AUTO FOCUS 버튼과 단발 자동 초점은 LA/WEB 모두 유지합니다.
   LA에서 기존 버튼까지 숨겼던 적용 범위를 바로잡아 버튼·기존 Agent/CTEC 동작을 복원했습니다.
   AF 영역이 사라진 경우와 펼쳐진 경우 모두 스크롤 최상단·최하단을 확인합니다.

3. WEB AGENT의 AF 제어 사용 체크는 연결마다 기본 ON입니다.
   HOME 등 다른 작업이 끝난 후 EO/IR 상태를 한 번 자동 조회합니다.
   기본 체크는 제어 사용을 뜻하며 렌즈 AF 모드를 강제로 ON으로 설정하지 않습니다.
   실제 ON/OFF와 지원 여부는 장비 응답을 표시하고 기존 초점 충돌 방지를 유지합니다.


[이어받은 기능]

촬영한 실제 PAN/TILT와 Row-first 정합 좌표를 JPG 옆 JSON에 저장합니다.
PRESET 연동은 표시할 기존 번호를 지정하며 자동 순회·영상 대조는 실행하지 않습니다.
번호 클릭은 기존 LA/WEB PRESET 단일 이동·렌즈 복원·수신 도착 판정을 사용합니다.
0/360도 순환, 행 중심 보간, 촬영 범위 밖 숨김, Uniform 여백·확대 창 좌표를 유지합니다.

RTSP UI 표시 주소와 내부 연결 주소를 분리합니다.
비밀번호의 #·!는 UI에서 그대로 표시하고 연결 시 UserInfo만 안전하게 인코딩합니다.
EO/IR 최초 연결·재연결·Profile 및 AI 연동 주소 형식과 로그 마스킹을 유지합니다.

정밀 조그·정밀 절대 이동은 UI에서 제공하지 않으며 실행 잠금을 유지합니다.
LA SYNC 숨김·비활성화, 남은 탭 균등 배치, FIRE/SMOKE 창 닫기 복원을 유지합니다.
기본 클릭 이동과 원본 IR 영상 비율을 유지합니다.


[개발 기본 원칙]

수정 코드에는 한국어 주석과 기능 사이의 빈 줄을 적용합니다.
로그는 상태·대상·실패 원인을 확인할 수 있게 남기며 인증정보는 가립니다.
작은 역할의 기존 함수를 재사용하고 불필요한 중복·미사용 코드와 반복 작업을 피합니다.
UI는 최상단·최하단 스크롤, 해상도 변경, 접힘·숨김 상태의 가독성과 잘림을 확인합니다.
변경한 범위에 맞는 빌드·오프라인 검증 후 정식·경량 공통 소스와 두 경로를 대조합니다.
이 텍스트도 매 수정·빌드마다 소스와 실행 폴더 및 배포 ZIP에 함께 갱신합니다.
