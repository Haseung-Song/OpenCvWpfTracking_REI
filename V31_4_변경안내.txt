실장비에서의 성능 향상 수치와 모든 운용 상황의 동등성을 보장하는 것은 아닙니다.
아래 V31 기능 설명과 실장비 확인 항목은 그대로 유효합니다.


[1. 줌을 반영한 영상 클릭 중심 이동]

무줌에서 사용하는 기준 화각은 유지합니다.
현재 광학 배율과 디지털 추정 배율을 함께 사용해 클릭 지점을 PT 절대 목표로 환산합니다.
각도를 단순히 나누는 대신, 화면 광선의 탄젠트 공간에서 배율을 보정합니다.
메인 영상과 분리 영상 모두 클릭한 채널의 줌 상태와 실제 영상 종횡비를 사용합니다.
영상의 검은 여백은 클릭 좌표에서 제외합니다.

MR500 EO의 광학 보정:

Zoom 위치 0~1000이 배율 1~90에 단순 선형 비례한다고 가정하지 않습니다.
기존 LEVEL 1~10 EO/IR 실측 매칭 위치를 활용한 구간 선형 보간을 사용합니다.
IR의 1~9배 선형 모델과 EO/IR 기준 광각을 이용해 상대 광학 배율을 환산합니다.
EO 위치 0은 1배, 위치 1000은 광학 90배 기준을 유지합니다.
최종 매칭 위치 940부터 광학 끝점 1000 사이는 90배까지 보간합니다.
EO/IR 화면 폭이 같다는 기존 측정 조건과 IR 선형 모델을 전제로 한 근사입니다.
실측 절대 화각이나 모든 위치의 실제 배율이 확정됐다는 뜻은 아닙니다.
EO 배율 입력과 상태 표시도 같은 광학 환산 모델을 사용합니다.

디지털 보정:

MR500 EO는 광학 최대 90배에서 디지털 1~4배, 총 90~360배를 추정합니다.
MR500 IR은 광학 최대 9배에서 디지털 1~4배, 총 9~36배를 추정합니다.
광학 위치 1000에서 성공적으로 송신한 GUI 줌 연속 조작 시간으로 추정값을 증감합니다.
D-ZOOM ON 요청만으로 즉시 4배를 적용하지 않습니다.
현재 기본값은 디지털 1~4배 이동에 10초이며 실측 시간이 아닙니다.
줌을 정지하면 추정 배율을 유지하고, 명시적 D-ZOOM OFF·세션 초기화 시 해제합니다.
디지털 추정 배율을 클릭 이동의 유효 배율에도 반영합니다.
오버레이는 추정 구간임을 표시하고 상태창은 같은 배율을 사용합니다.
D-ZOOM ON/OFF 적용 확인은 기존대로 유효 상태 응답으로 판단합니다.
배율 추정값이 증가했다는 이유만으로 장비 ON 확인으로 표시하지 않습니다.

Config/ControlTuning.xml:

WideHFov는 채널별 무줌 수평 화각입니다. EO 65.24도, IR 24.5도 기준을 유지합니다.
MR500 EO UseMeasuredSyncAnchors=true는 기존 매칭표 기반 환산을 사용합니다.
false로 바꾸면 기존 1~90배 선형 위치 환산을 사용합니다.
DigitalEstimateMax=4는 디지털 최대 배율 가정값입니다.
DigitalEstimateSeconds=10은 디지털 전체 이동 시간 가정값입니다.
실장비 확인 후 실제 지원 범위와 이동 시간에 맞춰 보정해야 합니다.
다른 장비 프로파일은 기존 광학 설정을 유지하고 디지털 모델을 임의 적용하지 않습니다.


[2. 영상 포커스별 PTZF 입력 복원]

메인 창에서 마우스가 EO 영상 위에 있으면 EO Zoom/Focus 및 EO 화각 기준 PT 제어를 사용합니다.
메인 창에서 마우스가 IR 영상 위에 있으면 IR Zoom/Focus 및 IR 화각 기준 PT 제어를 사용합니다.
EO/IR이 큰 화면인지 작은 화면인지와 무관하게 해당 영상 영역 기준으로 동작합니다.
영상 밖에 있으면 마지막 조작 채널이 아니라 현재 큰 메인 영상 채널을 사용합니다.
즉, 기본 EO 큰 화면 배치에서는 영상 밖의 PTZF 입력은 EO 기준입니다.
큰 메인을 IR로 전환했다면 영상 밖에서는 IR 기준입니다.
EO 분리 영상 창은 EO, IR 분리 영상 창은 IR 기준 제어를 유지합니다.
방향키, W/S 줌, A/D 포커스, Z/C 반복 속도 조절에 적용합니다.
Z/C는 공통 SPEED 값을 조절하며 PT 속도의 화각 기준은 현재 선택 채널을 사용합니다.
제어 채널을 바꾸는 경우 기존 누름 입력을 정지하며, 새 조작은 키를 놓고 다시 눌러 시작합니다.
비활성 메인 창 위로 마우스가 이동해도 활성 분리창의 제어 채널을 덮어쓰지 않습니다.
분리창 비활성화 시 전역 입력 사용 여부와 관계없이 해당 창의 로컬 누름 입력을 해제합니다.
텍스트 입력 중 단축키 보호, 운용 잠금 및 연결·정지 보호는 유지합니다.


[3. 실장비 확인 순서]

1) EO 큰 메인 상태에서 IR 작은 영상에 마우스를 두고 방향키·W/S·A/D를 확인합니다.
2) EO/IR 메인·작은 영상·분리창·영상 밖에서 각 채널 선택 규칙을 확인합니다.
3) 키를 누른 상태에서 채널을 바꾸거나 다른 창으로 이동했을 때 정지하는지 확인합니다.
4) 무줌, 중간 광학 줌, 최대 광학 줌에서 같은 상대 위치를 클릭해 중심 도달 오차를 기록합니다.
5) EO/IR 디지털 ON 후 GUI 줌을 조작하고 표시 배율·클릭 이동량·실제 영상 변화를 비교합니다.
6) 디지털 전체 이동 시간을 측정해 Config의 DigitalEstimateSeconds를 조정합니다.
7) D-ZOOM OFF, 연결 해제·재연결, 오래된 상태 수신 시 추정값과 적용 확인 문구를 확인합니다.

VIDEO CENTER 로그에는 채널, 원시 줌, 광학 모델, 광학 배율, 디지털 추정 배율,
유효 배율, 클릭 좌표, 추정 HFOV, PT 목표값을 남깁니다.
명령 송신과 실제 중심 도달은 별개이며, 실장비 오차는 아직 검증하지 않았습니다.
외부 리모컨이나 다른 프로그램에서 변경한 디지털 배율은 이 시간 기반 모델이 알 수 없습니다.
실제 디지털 배율 Telemetry가 없으므로 모든 배율에서 10% 이내 오차를 보장하지 않습니다.


[4. 기존 기능 및 배포]

V30_10의 LENS·통신 설정 배치, 클릭 이동 ON/OFF, 더블클릭 충돌 방지,
전원 상태·RTSP 분리, 프리셋·화각 SYNC·Event·Panorama 기능을 유지합니다.
원본 V31 ZIP은 수정하지 않고 V31_1 복사본으로 정리했습니다.
ZIP에는 V31_1 소스와 x64 Debug/Release 실행본을 포함합니다.
변경안내는 V31_2_변경안내.txt만 포함하며 사용자 제공 시험 스크린샷은 제외합니다.
