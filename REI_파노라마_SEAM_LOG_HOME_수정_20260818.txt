REI 파노라마 seam·로그·자동 HOME 수정 (2026-08-18)

1. 파노라마 합성 품질 개선
- 두 세로 촬영 행의 38% 겹침 영역 전체를 AddWeighted로 섞던 방식을 제거했다.
- 두 360도 행의 수평 시작 위치 차이를 순환 이동으로 먼저 보정한다.
- 축소된 겹침 영상에서 픽셀 차이가 가장 작은 동적 이음선을 탐색한다.
- 이음선 주변 8px에서만 feather blending하고 나머지 영역은 원본 한쪽을 유지한다.
- 가까운 난간, 건물 경계의 반투명 이중상과 전체 흐림을 줄인다.
- 대형 결과에서도 가중치 버퍼가 과도하게 커지지 않도록 64행 단위로 블렌딩한다.

2. 파노라마 로그 보강
- 버튼 시작/차단/사용자 취소 요청
- 행별 Tilt 이동 및 도착
- 72개 프레임의 Pan 목표/실제값, 크기, 촬영 완료
- 행별 OpenCV Panorama/Scans 정합 상태와 결과 크기
- 행 간 순환 이동량, overlap, seam 처리
- 저장 경로, 결과 크기, 전체 처리 시간
- 취소/예외/시작 위치 복귀/UI 잠금 해제

위 로그는 ConsoleLogHelper를 통하므로 Debug Console과 Serilog 파일에 함께 기록된다.

3. 자동 HOME 원복
- 장비 연결 직후 자동 HOME은 다음 조건을 모두 만족할 때만 실행한다.
  Control Agent 연결 + ROOFTOP/LA AGENT 모드 + EO 연결 + IR 연결
- EO 또는 IR 한 채널만 연결된 경우 자동 HOME을 실행하지 않는다.
- 자동 HOME을 위한 누락 채널 1회 강제 재연결 경로를 제거했다.

4. 검증
- OpenCvWpfTracking: Debug | x64 Rebuild 성공
- FireCandidateValidator: Debug | x64 Rebuild 성공

5. PAN/TILT SPEED Slider 연동
- 파노라마 촬영 시작 순간의 PanTiltSpeedLevel 값을 5~50 deg/s 범위로 저장한다.
- 저장한 속도를 72장 전체의 Pan/Tilt 절대 이동과 도착 Timeout 계산에 사용한다.
- 촬영 도중 UI 값이 바뀌어도 진행 중인 촬영 속도는 변경되지 않는다.
- 속도 5~20: 도착 후 1000ms 안정화
- 속도 25~35: 도착 후 1200ms 안정화
- 속도 40~50: 도착 후 1500ms 안정화
- 기본 Slider 값 30에서는 30 deg/s 이동 및 1200ms 안정화가 적용된다.
- 촬영 시작 및 프레임별 로그에 Slider 속도, 적용 속도, 안정화 시간을 기록한다.

6. 최신 생성 파노라마 기본 이미지
- 실행 시 bin 실행 폴더 아래 Panoramas에서 Panorama N.jpg를 검색한다.
- 가장 큰 N의 파일을 자동으로 기본 표시한다.
- 새 결과는 기존 최대 번호 + 1로 저장하여 항상 최신 번호가 된다.
- Panoramas 폴더 또는 생성 파일이 없으면 기존 내장 기본 이미지를 유지한다.
- bin/obj 삭제 후에는 생성 폴더도 없어지므로 자동으로 내장 기본 이미지로 복귀한다.

7. 파노라마 더블 클릭 확대 보기
- 하단 파노라마 이미지를 더블 클릭하면 별도 확대 창을 연다.
- 생성 이미지, 직접 불러온 이미지, 내장 기본 이미지 모두 지원한다.
- Mouse Wheel 1~8배 확대, 우클릭 배율 초기화, 더블 클릭 최대화, ESC 닫기를 지원한다.

8. 확대 보기 렌더 스레드 오류 방어
- 촬영, 정합, 블렌딩, 저장 중에는 더블 클릭 확대 보기를 차단한다.
- 확대창이 열린 상태에서 촬영을 시작하면 먼저 확대창을 닫는다.
- 확대창은 원본과 분리하여 최대 8192px로 디코딩하고 소프트웨어 렌더링한다.
- 확대창 생성 및 표시 예외를 처리하여 메인 프로그램이 종료되지 않도록 한다.

9. 고품질 정합 및 seam 계산
- 특징점 등록 해상도를 OpenCV 기본 0.6MP 수준에서 1.0MP로 높였다.
- seam 탐색 해상도를 기본 0.1MP 수준에서 0.6MP로 높였다.
- 최종 합성은 원본 입력 해상도를 유지한다.
- Panorama 모드의 수평 wave correction과 내부 구면 warping, 노출 보정,
  graph-cut seam, multi-band blending을 사용한다.
- 전경 난간과 건물 경계의 거친 절단 및 유령상을 줄이는 대신 처리시간과
  메모리 사용량은 기존보다 증가한다.

10. 확대 이미지 드래그 이동
- Wheel 확대 시 마우스 포인터 위치를 중심으로 확대/축소한다.
- 확대 후 좌클릭 드래그로 상하좌우 이동한다.
- 창 밖으로 과도하게 이동하지 않도록 이동 범위를 제한한다.
- 우클릭 시 확대 배율과 이동 위치를 함께 초기화한다.

11. PTZ 각도 기반 실사용 속도 최적화
- 10° 간격 36장 중 20° 간격 핵심 프레임 18장을 정합에 사용한다.
- EO Zoom 0~100 광각 조건에서 인접 프레임 중첩을 유지한다.
- 특징점 등록 0.8MP, seam 탐색 0.3MP의 균형 설정을 적용한다.
- 핵심 프레임 정합 실패 시 전체 36장 Panorama 모드로 자동 재시도한다.
- 구면 warping, 노출 보정, graph-cut seam, multi-band blending은 유지한다.

12. 정합 1분 목표 및 수직 절단 제거
- 정상 성공 경로는 30° 간격 핵심 프레임 12장을 사용한다.
- 특징점 0.35MP, seam 0.1MP, 합성 0.6MP로 제한한다.
- 1분 목표를 깨는 전체 36장 자동 재시도는 제거한다.
- 두 Tilt 행 정렬 시 원형 이동을 사용하지 않는다.
- 이동량만큼 양 행의 공통 영역을 잘라 건물/사다리가 영상 중간에서
  수직으로 잘리는 wrap seam을 제거한다.

13. 메인 창 Windows형 조작
- 34px WindowChrome caption과 8px resize border를 적용한다.
- 네 변과 네 모서리에서 일반 창처럼 크기 조절한다.
- 버튼, 입력창, Slider 등 조작 요소를 제외한 화면 배경을 끌어 이동한다.
- 작은 마우스 이동은 클릭으로 유지하고 drag 임계값을 넘을 때만 창을 이동한다.
- 최대화 상태에서는 겹친 사각형 복원 아이콘과 복원 ToolTip을 표시한다.
- 일반 상태에서는 단일 사각형 최대화 아이콘을 표시한다.
- 최대화 시 외곽 둥근 모서리를 제거하고 복원 시 다시 적용한다.
