REI V29_10 변경 안내
2026-10-08

이번 수정

연결·재연결 중에도 1번 프로필 선택 시 2번 EO / IR 카메라를 함께 맞춥니다.
선택은 다음 연결 설정이며, 실제 장비 변경은 연결 해제 후 다시 연결해야 합니다.
기존 영상과 재연결 주소는 유지하고 중복 연결만 차단합니다.

0x31 전원 판정은 기존처럼 기동형에만 적용합니다.
환경부·ER-WATCHER·LA의 전원 표시는 기존 방식으로 복원했습니다.
미확인 값을 OFF로 단정하지 않고 응답 지연 로그는 유지합니다.


1. 감지 기본 설정

FIRE / SMOKE SOURCE의 기본값을 IR ONLY로 변경했습니다.
EO ONLY와 BOTH(AUTO)는 필요할 때 선택할 수 있습니다.
이번 버전에서는 감지 알고리즘을 변경하지 않았습니다.


2. 탐지 구역 표시

저장 스냅샷과 실영상을 대조해 구역 위치와 크기를 보정합니다.
이동·줌 변경 후 안정화되면 다시 대조합니다.
대조에 실패하면 잘못된 구역을 표시하지 않고 적용을 보류합니다.

등록 구역은 연보라색 하나로 통일했습니다.
감지 BBOX는 FIRE 빨강, SMOKE 주황, AI 초록으로 구분합니다.
구역 이름표는 박스 바깥에 배치하고 겹침과 화면 넘침을 방지합니다.


3. 구역 설정창

구역이 하나면 미리보기를 보더 크기에 맞춰 크게 표시합니다.
기본 장면명은 [EO] 탐지 구역 1, [IR] 탐지 구역 1 형식입니다.
번호는 프리셋을 따르며, 이름은 장면 상세에서 수정합니다.

저장하면 저장되었습니다. 알림을 표시하고 창은 유지합니다.
종료는 X 또는 닫기 버튼을 사용하십시오.
등록 구역 표시는 기본 체크 상태입니다.


4. 연결 및 장비 혼선 방지

EO RTSP 인증 호환 기능과 LA 시험 장비의 줌 제어를 보완했습니다.
이동 후 캡처 동작은 사용자 현장 확인을 받았습니다.

연결·재연결 중에도 다음 장비 선택은 허용하고 중복 연결은 차단합니다.
안내 문구만 [EO] Already Connected... / [IR] Already Connected...로 바뀝니다.
기존 실영상은 로고로 가리지 않고 그대로 유지합니다.
다른 장비로 변경하려면 연결 해제를 완료해야 합니다.

WEB AGENT 프로필은 LA 연결이 끊겨도 지도·저장 파노라마를 유지합니다.
LA 프로필은 기존처럼 연결 완료 시에만 표시합니다.

EO / IR의 0x31 전원 응답 판정은 기동형 범위로 복원했습니다.
미확인 송신을 ON으로 단정하지 않으며, 응답 지연은 로그에 기록합니다.

환경부 MR500의 PAN / TILT 기본 속도는 40입니다.
다른 장비는 30을 유지하며, 수동 조절과 줌 연동 감쇄는 그대로입니다.


5. 저장 파일

구역·스냅샷: Config/FireSmokeZones.xml
프리셋: Config/Presets.csv
프리셋 위치 정보: Config/PresetPositions.xml
장비 설정: Config/Devices.csv

Presets.csv는 POSITION_SOURCE까지 12열로 정리했습니다.
CSV와 함께 데이터가 중앙 정렬된 XLSX를 생성합니다.
XLSX는 보기용이며 프로그램은 CSV를 읽습니다.

이벤트 불러오기는 AI와 FIRE / SMOKE 파일을 구분합니다.
잘못된 종류의 파일은 기존 목록을 유지한 채 거부합니다.


6. 화면 배치

버튼 크기와 간격, 문단 여백, PC TIME 중앙 정렬을 보완했습니다.
EO / IR의 BBOX 글자·선 두께를 화면 크기에 맞게 표시합니다.
창 확대·축소 시 잔상과 흔들림을 줄이는 처리를 추가했습니다.


7. 확인 사항

Debug / Release 빌드와 화면·전원·프로필 동기화 회귀 검사 207개를 통과했습니다.
실영상 구역 정합과 창 크기 조절은 현장에서 추가 확인이 필요합니다.
FIRE 오탐 개선은 후속 작업으로 진행합니다.
