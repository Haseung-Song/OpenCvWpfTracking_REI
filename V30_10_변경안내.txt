REI VIEWER V30_10 UI 변경 안내
2026-10-12
파일 버전: 30.0.0.10


[V30_10 핵심 변경]

배포명은 OpenCv_Wpf_Tracking_REI V30_10_UI_.zip입니다.
변경안내 파일명은 V30_10_변경안내.txt로 버전에 맞췄습니다.
이후 V30_11, V30_12 순서로 ZIP과 변경안내 파일명의 버전을 함께 올립니다.
기능은 기존 V30_0_UI_FIX10 최종본과 동일하며 명칭 변경 후 다시 빌드했습니다.

CTRL / RTSP 설정의 세로 여백만 줄여 불필요하게 생긴 스크롤바를 보완했습니다.
1, 2, 3 구역 사이의 구분 여백은 유지하고 버튼 크기와 기능은 변경하지 않았습니다.
마지막 IR POWER 버튼까지 기본 화면 안에서 보이도록 조정했습니다.
FIX9의 LENS, 상태 문구, 정렬, 단축키 동작은 유지합니다.


[FIX9 핵심 변경]

1. LENS 기존 배치 복원

FOCUS와 AUTO FOCUS 사이에 D-ZOOM ON / D-ZOOM OFF 버튼 한 줄을 유지했습니다.
ZOOM, FOCUS, D-ZOOM 버튼은 85 x 32 DIP이며 AUTO FOCUS는 기존처럼 180 x 32 DIP입니다.
EO/IR 모두 평상시 활성화 상태를 유지하며 LENS에는 슬라이더나 스크롤바를 추가하지 않습니다.
사용자 최종 선택에 따라 증감 버튼으로 변경하지 않습니다.
버튼 아래에는 요청 전송 / 응답 대기 / 적용 미확인 / 장비 ON 또는 OFF 확인을 구분해 표시합니다.
현재 제공 로그의 EO 응답 FLAGS=0x05는 설정 가능 / 상태 읽기 미지원입니다. 전송 성공만으로 적용 완료라고 표시하지 않습니다.
유효하고 최신인 Feature 0x1D 상태 응답이 도착한 경우에만 장비 ON/OFF 확인으로 표시합니다.

2. 오른쪽 장비 제어 가독성

TCP, EO, AI 첫 항목의 시작 위치를 같은 세로선에 맞췄습니다.
다음 항목 간격은 작은 마진을 유지합니다.
통신 설정 1, 2, 3 구역 사이 여백을 늘렸습니다.
4. DEVICE CONNECTION STATUS 제목은 왼쪽 정렬하고 통신 설정과 같은 배경 톤을 사용합니다.
PTZF/PRESET 스크롤 끝 위치에는 실제 콘텐츠 여백을 추가하여 가까운 제목이나 프리셋 상태 첫 줄이 반쯤 걸리지 않도록 보완했습니다.
중간 스크롤에서 화면 밖 콘텐츠가 가려지는 일반적인 스크롤 동작은 유지합니다.

3. SPEED 단축키와 안내 색상

Z / C를 계속 누르면 키 반복 입력마다 SPEED가 1~60 범위에서 지속적으로 감소/증가합니다.
메인창, 서브창 및 백그라운드 전역 입력에 같은 반복 동작을 적용했습니다.
단축키 안내는 방향키 연두색, SPEED 보라색, ZOOM 하늘색, FOCUS 주황색으로 구분했습니다.


[FIX8 핵심 변경]

1. 장비 연결 상태 간격 정리

- CONTROL의 TCP 상태는 ON/OFF 대신 Connected/Disconnected로 표시합니다.
- CAMERA의 EO/IR과 DETECT의 AI/FIRE/SMOKE는 고정 폭 칸을 제거했습니다.
- 각 항목 사이에는 10 DIP 마진만 적용하여 왼쪽부터 촘촘하고 일정하게 표시합니다.
- TCP 상태 색상은 실제 Control Agent 연결 상태 색상을 따릅니다.

2. PTZF/PRESET 하단 문구 잘림 보완

- PTZF와 PRESET 카드 사이의 불필요한 세로 간격을 줄였습니다.
- 두 탭의 스크롤 콘텐츠 하단에 16 DIP 안전 여백을 추가했습니다.
- 최하단 상태/도움말 문구까지 스크롤 범위에 포함하여 화면 경계에서 잘리지 않게 했습니다.


[FIX7 핵심 변경]

1. LENS 버튼 크기 통일

- EO/IR의 ZOOM, FOCUS, D-ZOOM, AUTO FOCUS 버튼을 모두 85×32로 통일했습니다.
- 활성/비활성 스타일 차이로 버튼 크기가 서로 달라 보이던 부분도 함께 제거했습니다.

2. D-ZOOM 버튼 상시 활성화

- EO/IR D-ZOOM ON/OFF 버튼은 Agent capability 및 상태 응답과 관계없이 기본 활성 상태를 유지합니다.
- 다른 LENS 버튼과 마찬가지로 일반 운용 상태에서는 항상 누를 수 있습니다.
- Agent 연결 또는 지원 상태는 전송 결과와 로그로 확인하며 버튼을 회색으로 비활성화하지 않습니다.
- HOME/ZERO, 파노라마, AUTO SCAN 등 전체 운용 잠금 중에는 다른 LENS 버튼과 함께 잠깁니다.


[FIX6 핵심 변경]

1. 클릭 이동 옵션

- 상단 기존 옵션 줄에 `클릭 이동`, `화각 비례 감속`, `감속 설정`을 가로로 배치했습니다.
- 별도 행을 추가하지 않아 장비 제어 영역의 세로 공간을 더 사용하지 않습니다.
- `클릭 이동`은 기본 ON입니다.
- ON이면 메인/분리 영상의 방향 화살표와 단일 클릭 중심 PT 이동을 함께 사용합니다.
- OFF이면 방향 화살표와 단일 클릭 중심 PT 이동을 함께 숨기고 비활성화합니다.
- OFF 상태에서도 분리 창 드래그와 더블클릭 확대/복원은 유지합니다.

2. 단일 클릭과 더블클릭 충돌 방지

- 영상 단일 클릭 중심 이동은 Windows 더블클릭 판정 시간이 지난 뒤 실행합니다.
- 두 번째 클릭이 들어오면 예약된 PT 이동을 취소합니다.
- 분리 창 더블클릭 확대/복원 시 중심 PT 이동이 함께 실행되던 중복 동작을 방지했습니다.

3. LENS 탭 배치 복원

- FIX4 기준 일반 버튼 85×32, AUTO FOCUS 180×32 크기와 기존 여백을 복원했습니다.
- EO/IR 카드를 동일 높이로 나누어 LENS 영역 전체를 채웁니다.
- 스크롤바와 큰 하단 빈 공간을 제거했습니다.
- 버튼을 과도하게 축소하거나 촘촘하게 배치하지 않습니다.

4. MR500 EO 90~360배 추정 표시

- D-ZOOM 상태 응답이 없어도 광학 위치가 1000에 도달하면 90~360배 추정 구간을 시작합니다.
- 영상 오버레이는 경계값부터 `EO x90.0 (추정)`으로 표시합니다.
- CURRENT STATUS는 `1000 / 1000 (x90.0)`부터 GUI ZOOM +/- 조작에 따라 같은 추정값을 표시합니다.
- 추정값은 광학 90배 이후 디지털 1~4배를 GUI 조작 시간으로 선형 추정한 표시값입니다.
- 실제 카메라 배율 텔레메트리가 아니며 MR500 EO 이외 장비와 IR에는 적용하지 않습니다.
- 명시적인 D-ZOOM OFF 요청 또는 응답이 있을 때 추정을 해제합니다.


[FIX5에서 유지되는 변경]

1. 영상 클릭 중심 이동

- EO/IR 영상의 실제 표시 영역을 한 번 클릭하면 해당 지점이 중앙에 오도록 절대 PAN/TILT 목표를 계산합니다.
- 디지털 줌 지원/ON/OFF/미확인 상태와 관계없이 중심 이동을 허용합니다.
- 최신 영상/PT/렌즈 수신, 연결, 입력 잠금, 이동 한계, 취소/정지 보호 조건은 유지합니다.
- 디지털 줌 활성 시 실제 화각 차이 때문에 중심 정렬 오차가 발생할 수 있습니다.

2. 지도 초기화

- 지도 확대 창에서 더블클릭으로 초기화하면 메인 지도도 기본 중심과 배율로 함께 복원합니다.

3. 배율 오버레이

- 메인 창과 분리 창이 같은 표시 조건을 사용합니다.
- Disconnected/재연결 상태에서는 숨기고 Connected 상태에서 복원합니다.

4. 영상 안내

- 메인/분리 창 안내 문구와 화살표 디자인을 공통 코드로 유지합니다.
- 영상 및 창 크기 변경 시 안내 크기를 다시 계산합니다.
- 안내 화살표는 마우스 입력을 가로채지 않습니다.


[기존 주요 기능]

1. FIRE/SMOKE 및 BBOX

- EO/IR 경고 배너를 수직 배치하며 동시 표시 시 겹치지 않도록 했습니다.
- AI/FIRE/SMOKE 문구는 BBOX 위에 직접 표시합니다.

2. PT 속도 및 감속

- 모든 장비의 초기 PT 속도는 40, 범위는 1~60입니다.
- 5, 10, …, 60의 12개 눈금을 표시하며 실제 값은 1단위로 조절합니다.
- Z/C 단축키로 PT 속도를 감소/증가합니다.
- 장비 Agent 자체 감속을 사용할 경우 GUI 감속을 꺼서 이중 감속을 피해야 합니다.

3. 복수 PTZF 입력

- 축과 입력 소유자를 독립 추적합니다.
- 한 축 해제 후 남은 입력 복구, 반대 방향 상쇄, 비상 정지 후 늦은 해제 보호를 유지합니다.

4. 전원 및 상태

- 기동형 0x31 범위를 유지합니다.
- 비기동형은 영상 수신으로 ON을 확인하며 영상 단절만으로 OFF를 확정하지 않습니다.
- TCP OFF 등 상태 이름과 값을 가까이 묶고 각 그룹 시작 위치를 정렬합니다.

5. D-ZOOM ON/OFF

- LENS의 EO/IR 각각 FOCUS와 AUTO FOCUS 사이에 D-ZOOM ON/OFF 버튼만 표시합니다.
- 중복 지원/상태 조회 버튼과 상태 문구는 제거했습니다.
- 공통 Feature 0x1D / E9 / EO target 0 또는 IR target 1 / value 0 또는 1을 사용합니다.
- ON/OFF는 배율 증감 명령이 아닙니다.

6. UI 및 입력

- TORUSS 회사 로고 다중 해상도 ICO를 EXE/창에 유지합니다.
- PC TIME 전체 문자열과 제목/창 버튼이 겹치지 않도록 유지합니다.
- AI 설정 카드 여백, 스크롤 내부 여백, 버튼 최소 높이를 유지합니다.
- 입력 중 로컬 문자 편집과 콤보 목록/ButtonBase/Expander 조작을 보호합니다.


[설정 및 실행]

- 실행 파일: bin/x64/Release/OpenCvWpfTracking.exe
- 장비별 감속/배율/화각 설정: Config/ControlTuning.xml
- 주요 설정값: MinRatio, MaxRatio, Exponent, MinSpeed, WideHFov
- WideHFov 기본값은 EO 65.24°, IR 24.5°이며 실장비별 보정이 필요할 수 있습니다.


[검증 범위]

- x64 Debug/Release 빌드를 수행합니다.
- 클릭 이동 기본 ON/OFF와 메인 방향 안내 표시 전환을 검사합니다.
- 단일 클릭 예약과 더블클릭 취소 경로를 검사합니다.
- LENS 카드 전체 높이 사용, 스크롤 제거, 버튼 크기와 패널 내부 배치를 검사합니다.
- MR500 EO 90→225→360배 추정, 정지, 역방향, 상한, 연결 안전 조건을 검사합니다.
- 지도 초기화와 WPF 레이아웃 및 localhost 모의 통신을 검사합니다.

실제 사용자 해상도/DPI의 마우스 조작, 실장비 PT 이동, 디지털 줌 및 중심 정렬 정확도는 현장 확인이 필요합니다.
명령 전송 또는 추정값 표시는 장비의 실제 도착이나 실제 배율을 증명하지 않습니다.
