[1. V31_0 / V31 - 줌 반영 클릭 중심 이동과 채널별 PTZF 제어]

영상 클릭 지점을 현재 광학 배율과 디지털 추정 배율로 보정하여 PT 절대 목표로 환산합니다.
단순 각도 나눗셈 대신 화면 광선의 탄젠트 공간에서 배율을 반영하며, 실제 영상 비율을 사용합니다.
클릭 좌표에서 검은 여백을 제외하고 메인·서브·분리 영상에 같은 기준을 적용합니다.

MR500 EO의 Zoom 위치 0~1000을 1~90배의 단순 선형 관계로 취급하지 않습니다.
EO/IR 실측 매칭 위치와 IR 1~9배 모델을 사용해 구간별 광학 배율을 보간합니다.
EO 위치 0은 1배, 1000은 90배이며 마지막 매칭 위치 940 이후도 끝점까지 보간합니다.
배율 입력, 상태 표시와 클릭 중심 이동이 같은 환산 기준을 사용합니다.

메인 창은 마우스가 올라간 EO/IR 영상 채널로 방향키·W/S·A/D를 라우팅합니다.
영상 밖에서는 현재 큰 메인 채널을 사용하고 분리 창은 해당 창 채널을 유지합니다.
제어 채널 변경과 분리 창 비활성화 시 기존 누름 입력을 정지·해제합니다.
Z/C 속도 반복 입력, 텍스트 입력 보호와 기존 운용 잠금을 유지합니다.

EO 디지털 배율은 GUI 조작 시간 기반 추정이며 실제 배율 Telemetry가 아닙니다.
초기 버전의 IR 디지털 추정 설명은 V31_3의 미지원 처리로 대체되었습니다.
최종본은 미지원 MR500 IR에 x36 추정을 적용하지 않고 최대 x9로 표시합니다.


[2. V31_1 - 반복 할당과 확인된 미사용 코드 정리]

RTSP 릴레이의 4바이트 미디어 헤더를 연결별로 재사용하고 쓰기 완료 후 다시 사용합니다.
누른 키가 없는 전역 키보드 감시 주기에서 목록 복사를 생략합니다.
속성명 배열, 입력 소유자 접두사와 RTSP 인증 마스킹용 구분자 배열의 반복 생성을 줄입니다.
입력이 없는 축 합산의 불필요한 LINQ 처리를 생략합니다.
호출·XAML 참조가 없는 AddShortcutHelp와 미사용 지역변수 등 확인된 데드 코드만 제거합니다.

수정 함수에 기능·날짜·수정 이유 주석을 보완했습니다.
입력·전역 훅·설정 검증 실패 로그에 예외 종류와 HRESULT를 추가합니다.
인증 정보 노출을 피하고 정상 종료에서 반복 오류 로그를 늘리지 않도록 정리합니다.
명령 패킷, 제어 순서, 정지 정책과 기존 안전상 상태 재검사는 유지합니다.


[3. V31_2 - 자동 감사 CSV와 XLSX 동시 접근 충돌 수정]

FireEvent 감사 CSV 추가 쓰기와 XLSX 생성기의 원문 읽기가 겹치는 공유 위반을 수정했습니다.
파일별 잠금으로 행 추가·헤더 검사·수동 내보내기·XLSX용 CSV 읽기를 직렬화합니다.
CSV 스냅샷 확보 뒤 잠금을 해제하고 파싱·압축하여 저장 잠금 시간을 줄입니다.
기존 헤더, DETECTED/CLEARED 기록과 XLSX 표 형식은 유지합니다.

저장 오류는 E-DATA-001 / 설정·데이터 저장으로 구분합니다.
안내는 AI 설정이 아닌 CSV 사용 프로그램·중복 Viewer·경로 권한을 확인하도록 수정했습니다.
외부 독점 잠금을 강제로 풀거나 과거 저장 실패 행을 자동 복구하는 기능은 아닙니다.
화면 이력이 남아 있으면 SAVE F/S CSV로 별도 보존할 수 있습니다.


[4. V31_3 - D-ZOOM 활성화 조건과 IR 미지원 처리]

광학 위치 1000 도달만으로 디지털 추정이 자동 활성화되던 경로를 제거했습니다.
EO는 D-ZOOM ON 송신 성공 또는 유효한 ON 상태 수신 이후에만 추정을 허용합니다.
미요청·송신 실패에서는 x90을 넘는 추정 배율을 표시하지 않습니다.
ON 요청 자체로 즉시 x360을 적용하지 않고 GUI 줌 조작 시간에 따라 증감합니다.
OFF 송신 성공·유효한 OFF 응답·명령 거절·세션 초기화 시 추정 상태를 해제합니다.

IR D-ZOOM ON/OFF는 연결 장비의 설정 지원이 확인된 경우에만 활성화합니다.
MR500 IR 미지원 상태에서는 요청을 막고 추정값을 초기화하여 최대 x9를 유지합니다.
EO/IR 배율 표시와 클릭 중심 이동에 같은 지원 조건을 반영합니다.
요청 송신 성공, 실제 장비 적용 확인, 추정 배율을 서로 구분합니다.


[5. V31_4 - POSITION·감속 설정과 연결·탐지 수명 방어]

POSITION 탭의 좌우 여백을 맞추고 상·하단 여백과 픽셀 스크롤을 정리했습니다.
탭을 다시 열면 최상단으로 이동합니다.
EO/IR 감속 기본 강도는 4, 최소 속도는 1이며 강도 1~4·최소 속도 1~60을 적용합니다.
기존 보더 안에 적용 버튼을 유지하고 최소 속도 1 미만의 임의 펄스 감속은 추가하지 않습니다.

클릭 이동 완료 후 추가 STOP·잔류 변화 감시 재정지·LA 키 해제 추가 위치 정지는 롤백했습니다.
기존 사용자 STOP·수동 입력 전환·클릭 이동 제한 시간의 안전 정지는 유지합니다.
수동 PT 속도는 원시 광학 Zoom 기준이며 디지털 추정만으로 추가 감속하지 않습니다.

FFmpeg Open/Read/Close의 자원 수명을 같은 잠금으로 보호합니다.
Open 취소, 중복 Disconnect 통합, 해제 중 새 연결 차단과 UI 밖 Decoder 정리를 보완했습니다.
TCP·AI 연결 세대와 세션별 수신 버퍼로 이전 작업이 새 연결을 닫거나 상태를 덮지 않게 합니다.
AI 연결 시도 제한과 취소된 연결 완료 폐기를 적용합니다.

FIRE/SMOKE OFF는 해당 BBox·Alert·ACTIVE만 정리하고 이력을 CLEARED로 보존합니다.
설정 변경 이전의 분석 결과와 수동 해제 이전의 지연 결과를 다시 표시하지 않습니다.
SMOKE SOURCE 시작값은 EO ONLY이며 최종 AI/VP 연결 정책은 14절 기준입니다.


[6. V31_5 - 특수 제어 탭과 EO/IR 프리셋 렌즈 복원]

우측 상위 탭에 특수 제어를 추가하여 통신 제어 / 운용 제어 / 특수 제어 / 이벤트 알림으로 구성합니다.
EO·IR 그룹의 접기·펼치기, 목록 내부 스크롤과 상·하단 여백을 제공합니다.
기존 LENS·D-ZOOM·AUTO FOCUS와 팔레트 단축 제어는 유지합니다.

공통 카메라 특수기능 ID 0x01~0x1E의 30종을 규격 대상 EO·IR에 나누어 배치합니다.
EO에는 Defog, 안정화, 영상 정지·반전, 밝기·대비·선명도, 역광, 주야간, WB,
Heat Haze, 노출·셔터·조리개, 채도·색조·감마와 D-ZOOM 등을 제공합니다.
IR에는 NUC/FFC, 팔레트·극성, AGC, 안정화·반전, 밝기·대비·선명도,
Heat Haze, 난류 저감, D-ZOOM과 자동 영상 조정 등을 제공합니다.
화면에 기능이 보이는 것과 실제 장비가 지원하는 것은 다릅니다.

E7 capability / Function 0x25의 supported·settable·valueType·범위·optionMask를 검증합니다.
지원 확인 전 제어를 잠그고 규격과 장비 범위의 교집합·지원 ENUM만 허용합니다.
E9 적용 요청과 E7 재조회 / Function 0x27 상태 확인을 분리합니다.
Defog/WDR 충돌, 조회 미지원·무응답·무효값·전송 실패를 구분합니다.
조회 간격 제한, 기존 운용 잠금과 세션 변경 시 capability·지연 응답 폐기를 적용합니다.

프리셋은 저장된 EO/IR Zoom·Focus 네 값을 복원하고 실제 수신값으로 확인합니다.
목표값을 현재값에 선반영하거나 단순 움직임·시간 추정만으로 완료하지 않습니다.
Zoom 복원 뒤 Focus를 복원하고 저장 렌즈 값 누락·오류는 INCOMPLETE로 남깁니다.
PRESET W도 GOTO·Pan/Tilt 도달 후 로컬 저장 렌즈 값을 복원합니다.
연결 세션 변경 시 이전 프리셋 작업을 취소합니다.
당시 IR 연속제어 우선 방식은 V31_8의 0x29 절대위치 우선으로 보완되었습니다.


[7. V31_6 - 영상 배율 버튼과 표시 상태 동기화]

EO/IR 영상 왼쪽 아래에 배율 버튼을 추가했습니다.
수치 배지만 숨기거나 다시 표시하며 한 곳의 변경을 메인·서브·분리 영상에 동기화합니다.
기본 표시 ON이며 미연결 영상은 배율 버튼과 수치 배지를 함께 숨깁니다.
버튼 클릭이 중심 이동·분리창 드래그·전체화면 전환으로 처리되지 않게 제외합니다.
배율 계산과 실제 렌즈·PTZF 제어는 변경하지 않습니다.


[8. V31_7 - 화면 높이에 맞춘 이벤트 페이징]

AI와 FIRE/SMOKE 이벤트 표의 페이지당 행 수를 실제 높이로 계산합니다.
작은 화면에서 22행을 강제로 표시하여 마지막 행이 보더 밖으로 잘리던 문제를 줄였습니다.
최대 22행은 유지하며 남은 이력은 PREVIOUS / NEXT로 확인합니다.
최종본의 뷰포트 기준 행 높이 보완과 9,999건 제한은 14절에 반영했습니다.


[9. V31_8 - Web Agent IR Zoom 0x29 절대위치 우선 복원]

환경부/Web Agent IR Zoom은 규격의 0x29 절대위치 요청을 우선합니다.
Zoom Position·EO Ratio 비례 이동·Zoom Sync·프리셋 IR Zoom 복원에 적용합니다.
표준 위치와 IR 원시 목표를 변환하고 새로운 렌즈 피드백으로 도달·정착을 확인합니다.
송신 성공만으로 완료하거나 UI 현재값을 목표값으로 덮어쓰지 않습니다.

피드백은 지속되지만 3초간 실제 위치 변화가 없을 때만 정지·후속 확인 후 기존 0x31로 대체합니다.
무피드백·실제 이동 중 미도달·송신 실패에서는 명령 중첩을 피하고 미완료로 남깁니다.
IR 0x29의 과거 화각×100 주석을 현행 Position 규격으로 정정했습니다.
옥상 장비 경로는 유지하며 환경부 LEVEL 10 끝점은 V31_10 예외를 적용합니다.


[10. V31_9 - 프리셋 렌즈 보정 시간 예산]

프리셋 렌즈 허용 오차는 표준 위치 기준 EO ±25, IR ±35입니다.
Pan/Tilt 이동 이후의 렌즈 복원과 정지 대기가 설정 Delay 1~60초를 공유합니다.
Delay 3초라면 Zoom은 최대 약 1.5초, Focus는 잔여 시간을 사용합니다.
먼저 끝나면 남은 시간만 기다리고 렌즈 복원 뒤 같은 Delay를 다시 더하지 않습니다.
단일 프리셋도 렌즈 보정은 설정 예산 안에서 제한하며 잔여 대기는 하지 않습니다.

시간 초과 시 해당 렌즈를 정지하고 실제값·미완료를 기록합니다.
반복 스캔은 다음 지점으로 진행할 수 있으며 큰 렌즈 이동은 예산 안에 완료되지 않을 수 있습니다.
Pan/Tilt 이동 시간, 수동 렌즈 제어와 일반 Zoom Sync 허용 오차는 별도입니다.
짧은 Delay에서는 3초 무이동 확인 전에 예산이 끝나므로 대체 명령을 무리하게 보내지 않습니다.


[11. V31_10 - 환경부 Zoom Sync LEVEL 10 IR 끝점 요청]

기존 로그·검증 CSV의 IR 끝점 미도달과 LEVEL 10 화각 오차를 확인했습니다.
환경부 LEVEL 10에 한하여 IR RAW 1000을 요청하고 RAW ±12로 도달을 확인합니다.
0x29 절대위치를 우선하며 기존 무이동 확인 후 대체 조건을 유지합니다.
EO 목표 940, LEVEL 0~9, 옥상 장비와 일반 수동·프리셋 매핑은 유지합니다.
어느 채널이든 도달을 확인하지 못하면 완료로 표시하지 않습니다.
FOV 정규화 폭 오차 계산식과 PASS 10% 기준은 바꾸지 않았습니다.
위치 도달과 실제 화각 성능시험 통과는 다르므로 같은 기준물로 재측정해야 합니다.


[12. V31_11 - 배율 문구 간소화]

배율 문구를 EO x1.0 / IR x1.0 형태로 간소화했습니다.
영상 라벨의 환산·추정 부가 문구를 제거했으며 시간 기반 계산의 성격 자체가 바뀐 것은 아닙니다.
최신 유효값이 없으면 EO — / IR —로 표시합니다.
